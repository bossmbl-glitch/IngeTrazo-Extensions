# 萊姆整合工具箱 1.0.0

整合參數櫃體、抽屜面板分格、門片／門組、百葉與玻璃門、窗型、開關／插座面板、統一配件資料庫、定位與材質工具。依使用者指示，將已完成的 rc3 封存為正式 1.0.0；本次不增加新功能。

- 單選／多選共用櫃體入口；只修改調整的欄位，保留各自尺寸、位置、分格與名稱；可排除個別櫃體、標示修改範圍及查看前後差異。
- 抽屜直接點分格圖，輸入高度即固定並分配其餘空間；每片可設定款式、把手、位置與顏色。
- 配件幾何共用、統一搜尋預覽及管理來源；自訂安裝基準、疑似重複分析及移除前引用提示。
- 面板點牆連續放置、計數與復原最後一個；離牆距離依款式個別記憶。
- 局部上色、木紋方向檢查與旋轉，尺寸簡單計算、分項範本及獨立重設框料／配件。
- 包含完整使用說明、40 項驗收清單、範例及安裝備份腳本。沒有加入各工具自動記住建模設定。

## 安裝與更新

目標 IngeTrazo 0.6.0／Windows x64，預設 cm。關閉 IngeTrazo，下載 ZIP 並解壓，將 `lime_integrated_tools_ingetrazo.py` 與整個 `lime_integrated_assets` 放入 `%APPDATA%\ingetrazo\plugins\`，覆蓋同名舊版後重新啟動。勿保留多份改名入口；配件資料庫不在安裝包內，不會隨更新覆寫。也可使用包內「安裝或更新.ps1」先驗證並備份舊檔。更新前保留原外掛與模型副本。

## 驗證與限制

正式包經 Linux／Qt offscreen 的 IngeTrazo 0.6.0 核心完整回歸、乾淨解壓載入與套件 SHA-256 校驗；數據見包內 RELEASE_VALIDATION.json。rc3 的公區測試成功修改 31 個櫃體把手，保留各自尺寸與位置，支援一次復原／重做。

**Windows 原生視口、GPU 效能、顯示縮放與 PowerShell 安裝仍待實機驗收；正式發布不代表這些項目已通過。** 引用檢查限目前模型與本機範本；不自動刪除疑似重複資料，也不猜測修復已破壞參數的舊模型。
