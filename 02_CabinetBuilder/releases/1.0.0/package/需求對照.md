# 1.0.0-rc2：依核可介面提案實作

1. 抽屜高度直接固定、等分與預覽，不再需要固定勾選或設定按鈕。
2. 分格圖放大；左圖與右側設定分開，外觀設定收合。
3. 單片把手沿用／不安裝／資料庫選用；位置按鈕、自訂邊距與複製把手設定。
4. 參數櫃體單一入口，同時處理單選與多選；原批次入口對櫃體也導向相同視窗。
5. 只套用實際調整欄位；其他尺寸、款式、分格、材質與使用者名稱保留。
6. 大量選取只顯示代表櫃體，完整清單可展開，列出略過原因與數量。

新增驗證見 `tests/test_cabinet_selection_editor.py`；測試結果與限制見 VALIDATION.md。
以下為 rc1 已實作需求的歷史對照；其中抽屜與櫃體批次的舊操作以本版使用說明為準。
