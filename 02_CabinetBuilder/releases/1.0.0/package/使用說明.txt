萊姆整合工具箱 1.0.0｜工具箱操作優化

正式版，依使用者於 2026-11-25 的指示發布。目標：IngeTrazo 0.6.0／Windows x64。
Linux 核心與 Qt offscreen 自動測試不代表 Windows 實機驗收。

安裝／更新
關閉 IngeTrazo，解壓整個安裝包，把 lime_integrated_tools_ingetrazo.py 與整個
lime_integrated_assets 資料夾覆蓋到原外掛位置，再重新啟動。
預設位置：%APPDATA%\ingetrazo\plugins\。
確認顯示 1.0.0；請勿同時放置多份改名的入口檔。
原 rc2／rc1 安裝包保留，可用於還原。

安裝包另有「安裝或更新.ps1」，可指定 -PluginDirectory。
它會驗證 MANIFEST、備份舊檔，再更新入口與資源；失敗時回復舊檔。
備份位置：%LOCALAPPDATA%\LimeToolbox\Backups\時間戳記。
目前環境無 PowerShell，腳本仍待 Windows 實際驗收；可使用上述手動方式。
使用者配件資料庫不在安裝包內，更新不覆寫。

一個入口，單選、多選共用
選取櫃體後，開啟「參數櫃體」或「修改選取物件」。
選一個時讀取單櫃設定；選兩個、八個或更多時，直接進入多櫃設定。
原批次修改入口遇到櫃體時，也會開啟相同設定，不需要另外走勾選、檢查、套用流程。
只有一個一般量體要轉換時，沿用基本設定的量體轉換操作。

多選櫃體：只改動你調整的欄位
1. 上方顯示可修改數量、略過數量；可展開清單查看名稱、原尺寸與原因。
2. 換把手：按「選資料庫款式」，選一款就會更新代表櫃體預覽。
3. 選「不安裝」會移除各櫃體的配件把手；選「不修改把手」會清除這次所有把手相關草稿。
4. 安裝位置可直接選上方置中、中央、下方置中。沒有調整位置時，各自保留原位置。
5. 離安裝面、垂直邊距預設空白；只有輸入才修改。單位預設 cm，可直接輸入 mm／cm／m。
6. 尺寸與款式頁的寬、高、深預設留空。只換把手時，每個櫃體原本的尺寸、門片款式、
   分格與顏色都保留；也不會把第一個櫃體的參數複製到其他物件。
7. 若明確選擇門片款式，才會統一選取櫃體所有面板的款式；其他未調整項目保留。
8. 底部會列出「本次只修改」的項目與數量，按「套用到 N 個櫃體」才寫入模型。
9. 套用時逐一驗證所有櫃體，顯示進度並可在準備階段取消。整批為一個歷史操作，
   Ctrl+Z 可一次復原，重做依主程式操作；完成後維持原選取。
10. 大量選取僅顯示代表櫃體與其餘數量，完整名單展開查看，避免重建整頁小圖。

多選保護與略過提示
隱藏、鎖定、非櫃體，以及原本參數或座標已無法讀取的物件會略過並列出原因。
例如「將修改 7 個；略過鎖定 1 個」。完成後會顯示實際修改與略過數量。
若選取、模型或編輯層級改變，會停用套用並要求按「讀取目前選取」。
新設定若無法通過框料、安裝位置等幾何驗證，整批不套用，顯示物件名稱與原因。
開放櫃沒有門片把手，C 把手門是內建造型；若試圖以配件設定替換或移除，會提示並停止。
如要改 C 把手門，請先明確改選可安裝配件的門片款式。

單櫃抽屜：點面板、輸入高度就預覽
1. 基本設定選「抽屜面板＋對應隔板」，設定欄數與每欄層數，進入「抽屜分格」。
2. 左邊為放大的正面分格圖，直接點要修改的面板，也能從選取面板清單切換。
3. 面板高度輸入完成後，約 0.18 秒自動固定該片，其餘未固定面板等分。
   不需要勾固定，也沒有「設定這片面板」按鈕。
4. 例如櫃高 120 cm，三格，中間面板改為 30 cm：上、下兩片各 44.4 cm。
   高度是面板實際高度，已扣上下邊縫；不是櫃內淨高。
5. 各欄獨立計算。按「這片改回自動等分」可解除該片固定。
6. 若高度超出或放不下框料，會保留上一個有效預覽，顯示錯誤並停用更新。
   改成可用高度後即可恢復；不會破壞原物件或清掉其他設定。
7. 調整立即更新草稿預覽，最後仍需按底部「建立／更新」才寫入模型。
   輸入後直接按更新或切換面板，會先處理尚未完成的輸入。
8. 左側分格圖與右側設定分開，捲動右側設定時，分格圖保持可見。

單片把手：直接選用
這片把手分成「沿用整櫃把手／不安裝／選資料庫款式」，不需要另外勾選使用。
把手位置可選沿用、上方、中央、下方或自訂；自訂可指定九宮格基準與邊距。
選款式或位置後自動預覽；可將把手設定套用到此欄或全部面板。
複製把手設定不會改動各面板的高度、款式或顏色。
單片款式仍可獨立設定；顏色收在「更多外觀設定」。

保留的功能
門組、玻璃、百葉、窗戶、面板放置、資料庫備份、收藏、範本、診斷與把手最佳化沿用。
原本各面板離牆距離的個別記憶保留，未新增各工具自動保存上次建模參數。
未套用草稿關閉或重新讀取時，仍可選套用／捨棄／繼續編輯。
輸入旁的鎖頭只限制編輯，與抽屜高度的自動固定分開。
問題可直接匯出診斷 ZIP，無須填表；診斷遮蔽私人路徑，不附整個模型。

建議驗收
先使用副本：單櫃改中間抽屜 30 cm → 換該片把手 → 複製到此欄 → 更新 → 復原。
再選 2／8／16 個不同尺寸櫃體，只換把手；確認尺寸、款式、分格、材質與自訂名稱保留。
再加入一個鎖定與一個隱藏櫃體，確認清單和完成訊息有略過數量與原因。
最後存檔重開，再讀取修改。詳細測試記錄見 VALIDATION.md，實際畫面見「畫面」資料夾。

已知限制
尚未完成 Windows 實機、顯示縮放與 PowerShell 安裝驗收，本版依使用者指示正式發布；這些實機驗收仍待完成。
被手動拆開、炸開、刪改參數，或櫃身與門片已分開移動的舊模型，不會猜測修復，
會列出無法編輯原因並保留原物件。準備完成進入原子寫入後，不接受中途取消。


rc3 新操作
多選櫃體：展開選取清單，取消勾選即本次排除；不會取消模型原選取。
「在模型標示修改範圍」只畫暫時外框，不改模型或材質；關閉視窗即清除。
「查看修改前後」列各櫃的原值與新值；底部只套用本次有修改的欄位。
設定完全相同會略過重建與復原紀錄。舊門片修復及轉換仍會執行。

長度可輸入 120/3、(20+10)*2 cm、125 mm；預設 cm，僅支援數字、括號及加減乘除。
「等比例調整寬高」須自行勾選，關閉後寬高獨立；不自動記住此設定。
常用範本可先選全部／尺寸／款式與框料／配件／款式與配件，再預覽及載入。
框料／配件恢復預設位於進階設定；只改設定草稿，預覽後按更新才寫入模型。

面板連續放置顯示本次數量；Backspace 或「復原最後放置」只復原自己的最後一次放置。
若期間有其他操作會提示，避免復原到別的物件。Esc 結束放置，視窗保留。
離牆正值朝外、負值嵌入，沿用各面板款式個別記憶。

配件資料庫
「管理來源」處理資料庫；「選用／插入」使用配件。來源修改不會自動改既有模型快照。
疑似重複分析只列出同幾何／材質／安裝基準的建議，不自動刪除，可取消分析。
查看使用位置及移除確認只檢查目前開啟模型與本機範本；其他未開啟檔案不在範圍內。
移除資料庫項目後，已嵌入模型與範本的快照保留。
自訂基準：先在場景選一個來源配件，按「載入目前選取」，再按「在模型點選安裝基準」。
點來源配件表面，確認預覽紅點與朝外方向後收錄；來源模型不會移動。
匯入檔案預覽要使用點選基準時，須先把來源模型放入場景並重新載入。

材質／木紋
選取整個參數物件，在群組上色選「整組／櫃身／門片／獨立框料／把手」。
指定範圍只處理模型已有的獨立部位；無獨立框料的單一實體不猜測拆面，會提示。
展開「木紋方向設定」可檢查目前方向、輸入角度並旋轉貼圖；幾何尺寸與其他實例保留。
局部上色及貼圖旋轉皆可 Ctrl+Z 復原。無貼圖或沒有匹配部位會提示。
