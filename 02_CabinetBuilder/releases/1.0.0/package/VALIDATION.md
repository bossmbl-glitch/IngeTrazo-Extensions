## 明確限制

- 自訂安裝點需從場景中的來源配件表面點選；匯入預覽需先放入場景。
- 部位上色使用已有獨立分組；不猜測拆開單一實體的框料與中央面。
- 配件引用檢查涵蓋目前模型與本機範本，不檢查未開啟檔案；移除來源保留內嵌快照。
- 疑似重複比對嚴格幾何／材質／基準，不自動刪除，也不保證找出拓撲順序不同的相似模型。
- 不猜測修復炸開、損壞參數或單獨移動櫃身／門片的舊模型；無法編輯會列原因。
- 沒有加入各工具自動記住建模設定；既有每款面板離牆記憶保留。
