# 本輪 40 項操作優化｜1.0.0

本版依使用者於 2026-11-25 的指示正式發布。下列是程式實作與驗收方式；自動測試結果見 VALIDATION.md，Windows 實機欄位仍待使用者驗收。
沿用 rc2 已有的工作流程、快取、復原與保護機制；沒有加入各工具自動記住上次建模設定。

| 編號 | 項目 | 操作與預期結果 |

| 2 | 底部主要動作 | 建模工具底部預覽／建立或更新；高度、CAD、地板、旋轉、變形與上色的最終動作也位於捲動區之外。 |
| 3 | 常用優先、細項收合 | 基本／框料／配件／進階分頁；範本、外觀與木紋細項按需要展開。 |
| 4 | 配件選用一致 | 線板、把手、面板都在統一資料庫搜尋、選取、預覽、選用／插入。 |
| 5 | 使用與管理來源分明 | 庫中收錄／儲存按鈕標「管理來源」，選用／插入保留獨立按鈕；改來源不會暗改模型快照。 |
| 6 | 錯誤對象與欄位 | 多櫃無效設定列物件名；單櫃補物件／面板位置；可辨識的尺寸欄標示錯誤。 |

## 建議先驗收的五條完整流程

1. 選 8 個不同尺寸櫃體，只換把手，排除其中一個，查看前後與外框標示後套用。確認只改 7 個且所有尺寸位置保留；一次 Ctrl+Z 全部回復。
2. 抽屜選第 2 片輸入 30 cm，選資料庫把手，上方置中、距上 3 cm；確認圖上基準尺寸後建立，再讀取。
3. 面板連續放 3 個，Backspace 一次，再放一個，Esc 結束；確認個數、朝外方向與每款離牆距離。
4. 資料庫收錄一個來源，點自訂安裝基準，檢查預覽後使用；確認原來源及已放置實例不被來源管理修改。
5. 複製兩個共用配件的櫃體，只對其中一個上色或旋轉木紋；確認另一個保留，再測復原與重做。

尚待 Windows x64：安裝與還原、原生視口拾取／高亮、實際 GPU 表現、100%～200% 顯示縮放與長清單操作。離線測試不代替這些項目。
