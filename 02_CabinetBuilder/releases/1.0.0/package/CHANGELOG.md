# 萊姆整合工具箱版本紀錄

## 1.0.0（2026-11-25）

- 依使用者指示將 rc3 封存為正式 1.0.0；功能及資源與 rc3 相同，更新版本號、發布說明與套件清單。
- 包含參數櫃體、抽屜分格、門組／百葉／玻璃門、窗型、統一配件庫、面板放置、局部材質與木紋方向，以及本輪 40 項操作優化。
- 保留 rc3 與舊版還原包；資料庫不隨外掛更新覆寫。
- 正式發布不代表新增 Windows 實機通過紀錄；驗證範圍及限制見 VALIDATION.md。

## 1.0.0-rc3（2026-11-24）

- 實作本輪 40 項操作優化；詳細位置與驗收步驟見「40項驗收清單.md」。
- 多選櫃體可暫時排除個別項目、在視口標示修改範圍、查看修改前後；實際結果列出修改與略過數量。
- 設定相同略過重建與歷史紀錄；舊門片幾何修復、原始模型轉換仍照常執行。
- 長度支援安全的加減乘除與括號；去除多餘小數，寬高可明確勾選等比例調整。
- 範本預覽及分項套用；框料、配件各自重設，不自動記住各工具建模設定。
- 抽屜標明固定高度或分配剩餘空間，沿用把手顯示名稱；正面圖標示把手基準距左／距下及離安裝面。
- 面板連續放置計數、Backspace 復原最後一個且可繼續放置；保留每款面板的離牆記憶。
- 配件庫新增疑似重複分析、來源移除前查看模型／範本引用、從場景點選自訂安裝基準。
- 材質工具新增櫃身／門片／獨立框料／把手範圍，木紋方向查看與可復原旋轉；編輯私有網格以保護其他共用實例。
- 統一底部操作、模式與基準提示、搜尋別名、長名稱提示、無效輸入保留上一有效示意，更新內建說明。

保留 rc2；候選版，未正式發布。Windows x64 實機及顯示縮放仍待驗收。

## 1.0.0-rc2（2026-11-24）

- 參數櫃體入口依選取數量開啟單櫃或多櫃設定；多選不再需要另開勾選式批次視窗。
- 多櫃只建立實際編輯欄位的修改草稿；空白尺寸保留各自原值，把手修改不改尺寸、款式、分格或自訂名稱。
- 代表櫃體即時預覽、完整選取清單、略過原因、選取變動保護、準備進度與一次復原。
- 抽屜面板輸入高度後自動固定並等分其餘面板；移除固定勾選與設定這片按鈕。
- 放大分格圖，左側圖與右側設定分開；把手改為沿用／不安裝／資料庫款式，位置直接選擇。
- 新增把手設定複製到此欄或全部面板；只複製配件設定，保留面板高度與外觀。
- 無效高度保留上一個有效預覽；無法參數編輯的原物件列出原因，不阻止開啟其他櫃體設定。
- 修正 Qt 旋轉矩陣精度造成的尺寸數值漂移，以及套用後代表預覽快取未更新。

Windows 實機尚待驗收，未正式發布。rc1 與其安裝包保留，不覆寫。

## 1.0.0-rc1（2026-11-24）

- 新增以正面面板操作的抽屜分格：各欄獨立固定高度與等分，每片款式／把手／顏色。
- 新增修改選取物件入口、巢狀定位、批次修改與影響範圍，列出隱藏／鎖定略過原因。
- 新增混合值提示、僅套用勾選欄位、批次原子復原、主動更新既有配件快照。
- 新增手動預覽、收合範本、抽屜專頁、未套用提醒、忙碌防重入與視窗釋放。
- 資料庫新增收藏／最近使用、保留識別碼更新來源模型與失敗回復；匯入與最佳化新增進度與取消。
- 新模型記錄 schema 2 與工具版；舊模型只讀相容，較新模型提示更新工具箱。
- 診斷遮蔽私人路徑、郵件、憑證與模型 blob，包含安裝包指紋。
- 新增安裝備份腳本、模型檢查、使用說明、抽屜實際範例與需求 1～41 對照。
- 修正新增面板快取鍵、配件改名後刷新、舊版 CY 自訂材質匹配，以及獨立面板座標。

此版保持候選包狀態，尚未完成 Windows 實機驗收與正式發布。
前版完整紀錄保留於 ../toolbox-v0.34.2/CHANGELOG.md，前版套件未覆寫。
