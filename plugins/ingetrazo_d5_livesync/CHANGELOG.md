# IngeTrazo D5 LiveSync 累積更新紀錄

## 0.9.10-test.1 — 2026-11-12，測試版，待 Windows／D5 驗收

以儲存庫實際 0.9.9 原始碼為基礎。開發基準最初為 bee6c44，後同步 develop 的 2cd4d7e 管理文件；兩者 LiveSync 程式完全相同。未發布正式版。

- 核對診斷 6／7，及官方 ingelibre/ingetrazo 的 v0.6.0（e61132a7f8a098ca77fb6b0e7cac488c1bd410cb）。
- 一般群組原生移動／旋轉：原生程式修改頂點、UV 投影及 axes，xform 可以維持 None。這些已追蹤命令可在 UID、路徑、階層及其他屬性檢查通過後，使用原生 IGZ 儲存器局部更新受影響最外層群組。有獨立 xform 的元件保留原有快速矩陣更新。
- 材質工作室 0.5.1：支援已核對 engine.py 的 PaintCommand。以正規化換行後的 SHA-256 核對來源、完整命令追蹤、明確目標群組及未分組網格修改序號鏈判定。允許該命令造成的子群組複製與布林 component 標記清除；其他屬性、識別或階層不符則退回完整同步。
- PaintCommand 即使沒有上色未分組面仍會增加 scene.mesh 修改序號；只有已核對命令且沒有未分組面目標、未分組網格識別相同、每筆修改序號完整銜接時才接受這項副作用。
- 材質參照檢查涵蓋背面材質，避免漏掉共用同名材質的未分組面；局部快照包含所需背面材質庫項目。
- 沒有變動時，只有本連線已成功確認的版本與目前內容版本、命令追蹤、網格追蹤、群組、全域設定和貼圖檔案狀態一致才略過。不建立新 revision、不改 latest.json、不呼叫匯出器或 D5。手動「完整更新一次」及接收端要求完整更新不略過。
- 新增 sync_requested／sync_skipped、觸發來源、排程世代、內容版本、實際屬性欄位及移動前後有界頂點樣本。樣本及修改序號只作診斷，並非完整幾何證明。
- 原生 History 吞下的失敗／拒絕命令亦會使局部證明失效。
- 未更動 D5 importer、物件識別生成、圖層 hold 合併規則、官方 SDK 或使用者模型。局部處理依舊使用原有接收端合併與完整同步退路。

本地結果：22 項自動化測試通過，使用實際 0.6.0 core、原生 IGZ 匯出及局部合併；Python 語法編譯、diff 空白檢查通過。沒有執行 Windows／D5 實機測試，沒有新的實機秒數。

限制：這次一般群組移動走局部快照，不宣稱已轉為純矩陣傳送或達成 7 秒。材質工作室來源不同、缺少可讀 engine.py、編輯群組內上色、未分組面或其共用材質受影響、追蹤中斷、範圍過大等仍完整同步。先完整同步成功一次後才能最佳化；本次不改變既有完整合併的 hold 基準要求。
