IngeTrazo → Blender → D5 自動同步 0.6.0（燈具佈光與連動燈組）

新增：點燈具模型佈光
1. 在 D5 整合工具列按「四盞小燈」圖示（燈具佈光／連動燈組）。
2. 選擇聚光、點光或燈條；位置可選底面中心或模型中心。
   預設為底面中心向下 0.20 cm，也就是 2 mm。燈條可設定長度。
3. 按「點選一組」，連續點四個燈具，就會建立四盞同組光源。
   同一組內重複點同一燈具不會增加第二盞。每盞建立可 Ctrl+Z 復原。
4. 按 Esc／Enter 或「完成」結束這組，保留已建立的燈。
   再按「點選一組」，新點的燈具就屬於下一組，種類可重新設定。
5. 也可以先用原生選取工具選好數個燈具，按「選取佈光」一次建立一組。
   整批可一次復原。每個燈具須為獨立群組／元件；散面請先成組。
   若多個燈具包在外層群組內，可先用原生工具進入外層群組，再點內部燈具。
6. 在光源清單選取其中一盞，預設勾選「連動整組參數」。
   修改亮度、色溫、啟用、光束角、燈條長寬，會套用到該組同類光源。
   名稱、位置、瞄準方向與刪除仍只影響單盞。取消勾選可單獨修改參數。
7. 先按 D5 啟動同步；光源以穩定群組 ID 和「燈組 1／燈組 2…」組名傳送。
   使用官方 SDK 的 D5SetPathElementName、group_id、path，非僅加相同名稱。
   官方 D5 支援同類光源成組調整，但本版尚未在 D5 畫面確認新增燈組的接收結果。
   新增佈光、連動及官方 SDK 離線 API 測試已通過；詳見驗證紀錄。

位置以包含子群組的世界座標外框計算：「底面中心」是外框 XY 中心及最低 Z，
「模型中心」是外框中心；不是曲面表面取樣或質心。向下為世界 Z 負方向。
燈條以此點為中心，沿模型世界 XY 外框較長的方向放置；可再用原生工具移動／旋轉。
建立後光源是獨立黃色定位模型，移動原燈具不會自動帶動光源；可一併選取移動。
黃色代理幾何不送入 D5，原燈具模型照常同步。燈組關聯隨 IGZ 保存。
這是 IngeTrazo → D5 單向同步，D5 內調光不會回寫 IngeTrazo，後續同步可能覆蓋。
建議需要持續聯動時在 IngeTrazo 整組調光；要在 D5 完成最後調整時先停止同步。
官方批次調光說明：https://docs.d5render.com/user-guide/lights/how-to-edit-multiple-lights-at-once

用途
在 IngeTrazo 上方的整合工具列按「D5」，
後續模型修改由插件自動製作快照、交給背景 Blender，再經官方 D5 Sync 傳送。
不需要反覆手動匯出及匯入。Blender 不會開啟工作視窗。

本版改用 IngeTrazo 原生 IGZ 作為中介，以保留群組識別和材質資訊。
D5 接收的是官方 Blender LiveSync 資料，不是手動重新匯入 IGZ 或 GLB。
官方 Sync 安裝檔不包含在本壓縮包內，須另外安裝。

本機版本
IngeTrazo 0.5.11、D5 Render 3.1.1.0755。
已在 Blender 4.5.4 LTS 與 5.2.3 LTS 通過官方 Sync 載入／適配器初始化；5.2.3 另通過
模型新增、移動、材質更新、刪除、代理排除，以及燈光資料傳送格式測試。
本版接受 Blender 4.5～5.2，實際啟動前會檢查所選版本，不能將以上測試視為每個中間版本均已實測。
官方 D5 LiveSync 使用 1.0.0.0028；請用官方最新安裝包替所選 Blender 版本安裝。
Blender 4.5 使用 Python 3.11，5.2 使用 Python 3.13，不要跨版本直接複製 d5_export 資料夾。
Blender 5.2 的 D5 實際場景連線仍需在目的電腦完成首次關聯；本次沒有重新操作使用者的 D5 場景。
來源插件 API 仍可能變動，軟體升級後需要重新驗證。

開始使用
1. 插件資料夾 ingetrazo_d5_livesync 放在：
   %APPDATA%\IngeTrazo\plugins\
   如果 IngeTrazo 已開啟，先保存工作並重新啟動以載入插件。
2. 開啟模型。上方是一排「D5／更新／停止／設定」，右側是光源圖示。
3. 按「D5」先執行背景啟動檢查；通過後自動開始同步。查看狀態及路徑時按「設定」。
   支援標準安裝路徑、登錄的自訂磁碟位置；可按「重新偵測安裝位置」，或手動選擇 Blender、D5。
   仍有效的使用者路徑會保留，只有失效的舊路徑才自動替換。
   找不到 Sync、裝在其他 Blender 版本、元件載入失敗或程序崩潰，會顯示具體原因。
   無法解決時按「複製診斷」，將文字貼回此聊天；不需要自行尋找日誌檔。
4. 首次連接時，D5 可能要求建立專案或關聯已有模型；在 D5 完成選擇。
   新背景連線可能再次要求關聯。請只選要由此模型更新的項目。
5. 編輯模型，放開滑鼠並停止操作約 1 秒後，插件自動送出最新版本。
   若上一版尚未完成，新的修改會合併等待，不會排成無限佇列。
6. 「停止背景同步」會結束此插件自己的 Blender 工作程序。
   關閉 IngeTrazo 也會停止程序。D5 場景保留。

行為及範圍
- 同步不代替使用者儲存模型。新增／編輯光源會建立／修改定位群組並可復原，請保存 IGZ。
- 以目前文件為單一同步來源。切換／關閉文件時停止，須對新文件重新開始。
- 支援幾何、群組、材質和位置傳遞；群組編輯模式仍輸出整份模型。
- 本版同步工具列建立的 D5 點光、聚光、燈條；不連動原生 Render 燈光、攝影機、天候或最終出圖。
- 這是完整快照加批次同步，不是逐頂點增量、逐幀串流。
- D5 正在出圖或更新時會等待。來源貼圖遺失時會停止並顯示原因。
- 中途斷線或發生錯誤時會顯示錯誤，需要修正後重新開始。
- D5 原生材質替換、散佈、特殊材質在多次同步後的保留情形尚未驗證。

D5 光源（整合在同一排，只有圖示，滑鼠停留可看名稱）
從左到右：燈具佈光、點光源、聚光燈、燈條、移動、瞄準、刪除、光源設定。
1. 點光源／聚光燈：按圖示後，在模型上點選位置；Esc 取消。
2. 燈條：點選起點，再點終點。送到 D5 的是真正燈條類型。
3. 選取：點選黃色燈具定位模型，亦可在「光源設定」清單選取。
   點光為小型八面體、聚光為錐形、燈條為長條盒；全部是 IngeTrazo 原生群組。
4. 移動：選取定位模型後，用 IngeTrazo 一般移動工具操作；四向箭頭也可切換到一般移動工具。
   可利用模型面、端點與原生捕捉功能定位，不需輸入座標。Ctrl+Z 復原。
   完成原生移動後，燈光位置會自動排入 D5 同步。定位模型保留於來源 IGZ。
   同步快照會排除定位群組及其幾何，D5 只收到對應燈光與正式場景模型。
   請保持定位模型為完整群組；若分解成散面，插件會停止同步並要求復原分解，避免誤傳。
   舊版光源開啟後會自動補上定位模型；此操作可復原，保存 IGZ 後會保留。
5. 瞄準：聚光燈／燈條可點選照射目標；點光不適用。
6. 光源設定：調整亮度、色溫、啟用；燈條可調長度／寬度，聚光可調光束角。
7. 刪除：刪除定位群組或按光源垃圾桶會移除對應光源；Ctrl+Z 可復原。取消「啟用」也會停止其在 D5 的照明。
燈條長度與寬度使用公尺。資料隨 IGZ 保存，編輯不依賴 Blender 視窗。
需先按「D5」啟動同步，後續光源編輯才會自動送出。
光源在 IngeTrazo 管理，屬單向同步；直接在 D5 修改這批光源可能被下次同步覆蓋。
獨立建立於 D5 的其他光源不在此插件的管理清單內。
上一版原生 Render 燈光不會自動轉成 D5 光源，也不會刪除。

紀錄與資源
面板「開啟同步紀錄」開啟這次連線的工作目錄：
%LOCALAPPDATA%\IngeTrazoD5Bridge\sessions\session-…\
worker.log：背景程序及官方 Sync 訊息。
%LOCALAPPDATA%\IngeTrazoD5Bridge\plugin.log：工具列載入與按鈕錯誤紀錄。
status.json：階段及已確認版本號。
timings.jsonl：每版快照、Blender 接收、官方傳送的耗時。
只有官方原生傳送回報成功才確認該版，不將「寫出快照」當作同步完成。
傳送成功也不代表 D5 畫面已完成渲染收斂。
每次連線會保留最近兩版快照及診斷檔；舊連線資料夾不會自行刪除。
需要釋放磁碟時，在停止同步後可刪除不需要的舊 session 資料夾。

移除
先停止同步並關閉 IngeTrazo，再移除 plugins 下的 ingetrazo_d5_livesync。
官方 Blender Sync 與 D5 安裝不受影響。
