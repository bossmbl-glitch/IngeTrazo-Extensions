v2.2.0 試用版｜圖庫文字、編輯輪廓、連續放置剖面整合
適用 Windows / IngeTrazo 0.6.0；以使用者確認正常的 v2.1.6 為基礎。

一、圖庫文字
- 縮圖與名稱分成獨立繪製區域，名稱 11 pt 起、深色半粗體，最多兩行。
- 卡片改用 QAbstractButton，避免主程式對 QToolButton 高度的樣式限制裁掉名稱。
- 依字體行高計算卡片高度，字體變更時重新計算。
- 長名稱省略顯示；滑鼠停留顯示完整原名及來源提示。原始檔案不重新命名。
- 增加卡片與圖庫區塊間距。

二、移除「實驗中」
- 移除面板按鈕與獨立啟動入口。
- 已正常的滑鼠繪製、水平踢腳、牆面線板方向計算保持 v2.1.6。

三、編輯輪廓
- 選取本套件建立的頂層輪廓群組，再設定面板，按「編輯輪廓」。
- 勾選要套用的項目，預設只有「輪廓／名稱／寬／高」。
- 支援：放置點、旋轉、鏡像、水平／垂直偏移、材質、標籤、轉角連接及一般擠出模式。
- 未勾選項目維持原值；原路徑、踢腳／牆面方向、群組識別與其他擴充資料保留。
- 支援同時更新多個合適群組，全部預先驗證後再一次提交；一次 Undo 復原整次編輯。
- 整體移動、旋轉、縮放過的線板，依原生成網格與現有頂點推回定位，避免跳回原位置。
- 「全部」全選、「清空」取消勾選、「取消」不修改。
- 本版只支援有保存剖面與參數的本套件群組；不支援任意手繪幾何或巢狀子物件。若手動改過拓撲／局部變形導致無法對應，會提示而不覆寫。
- 重建時若各面材質／屬性不同且沒有勾選材質，會提示，避免直接遺失逐面設定。
- 擠出目前只有「一般」，勾選該項只記錄一般模式，不額外增加擠出種類。

四、放置剖面
- 面板設定剖面、寬高、旋轉、鏡像、基準點及偏移後按「放置剖面」。
- 滑鼠移動即預覽包含面的 2D 剖面，點一下建立一個獨立群組。
- 放置後繼續保持蓋印模式；每一份都是單獨 Undo 步驟。
- 自動模式使用可取得的吸附面方向；無面方向時預設 XY。端點／邊吸附不一定提供面方向。
- 右鍵盤方向鍵：右 = YZ 平面、左 = XZ 平面、上 = XY 平面、下 = 恢復自動。
- Esc 結束蓋印，已放置的剖面保留。材質與標籤套用面板設定。
- 放置剖面也保存本套件參數，可吸取設定或使用「編輯輪廓」更新。

介面排列
- 移除「實驗中」後，八個主要工具採兩排四顆，避免狹窄面板擠壓名稱。
- 第一排：滑鼠繪製、沿路徑、沿面外框、吸取剖面。
- 第二排：編輯輪廓、放置剖面、方向切換、進階設定。
- 寬高欄位沿用既有 mm，未修改資料庫尺寸或原剖面檔案。

安裝
1. 完全關閉 IngeTrazo。
2. 將舊 ingetrazo_profile_builder_v0_1 資料夾備份至 plugins 以外，不要同時載入新舊兩份。
3. 將 ZIP 內 ingetrazo_profile_builder_v0_1 整個放入 %APPDATA%\ingetrazo\plugins\。
4. 重新啟動；面板標題應顯示 v2.2.0。

簡單驗收
1. 開啟剖面圖庫，確認最近使用及圖庫各卡片文字可見，長名可停留查看。
2. 確認面板沒有「實驗中」，且原踢腳與牆面線板繪製正常。
3. 選取舊版線板群組、更換面板剖面，按「編輯輪廓」，只勾輪廓套用，確認路徑位置不變；Undo 復原。
4. 按「放置剖面」，在不同位置連點三次，確認三個含面的獨立群組；Undo 一次只移除最後一份。
5. 按 Esc 離開蓋印，確認已放置內容仍保留。

驗證
- 30 個測試腳本通過；另檢查 150% 與 200% Qt 縮放。缺歷史 v1.6 ZIP 的一個舊測試未執行。
- 使用 IngeTrazo 0.6.0 原始碼的實際 Mesh、Group、History 與離屏 Qt 測試編輯、定位、連續蓋印及 Undo/Redo。
- 主面板、卡片與屬性對話框有離屏截圖，附於「介面預覽」。
- v2.1.6 掃掠、三角化、邊線顯示核心函式保持一致。
- 尚未在使用者 Windows 的 OpenGL 桌面實測滑鼠吸附、顯示縮放或大型專案。
