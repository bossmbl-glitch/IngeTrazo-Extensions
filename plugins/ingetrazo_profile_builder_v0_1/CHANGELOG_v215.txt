v2.1.5 試用修正版｜水平踢腳方向穩定
適用：Windows / IngeTrazo 0.6.0。未於使用者 Windows 實機驗證。

本版修正：
1. 新增「滑鼠方向」：預設「水平踢腳（高度沿 Z）」，另保留「牆面／空間（原方式）」。
2. 水平模式在第一段就固定 Z 為剖面高度方向，後續轉角不再切換成另一平面。
3. 起筆可取得有效牆面法線時，依該方向選擇厚度側；邊／端點無法取得法線時使用固定預設側，按 F 或繪製中的「方向切換」反轉。
4. 預覽第一段和確認第一段使用相同規則；之後不再依暫時封閉面積重新翻面。
5. 預覽、Space/Enter 完成、回到起點閉合共用同一份方向設定；群組記錄該設定。
6. 一般「滑鼠繪製」和「實驗中」在水平模式都使用同一個修正核心。
7. 水平模式提供通過起點的 XY 工作平面；若吸附到不同高度則顯示提示，不自行改動路徑高度。
8. 垂直牆框及非共面路徑請先改用「牆面／空間（原方式）」再起筆；本版未擴充該舊模式的跨牆能力。
9. 面板原有剖面尺寸欄位沿用 mm；本次沒有改動單位或資料庫格式。

安裝：
1. 完全關閉 IngeTrazo，將舊的 ingetrazo_profile_builder_v0_1 備份到 plugins 目錄以外。
2. 解壓縮本 ZIP，將 ingetrazo_profile_builder_v0_1 放入 %APPDATA%\ingetrazo\plugins\。
3. 啟動後面板標題應顯示 v2.1.5；不要同時放置兩份外掛。

照本次案例測試：
1. 滑鼠方向選「水平踢腳（高度沿 Z）」。
2. 選原剖面：左下、旋轉 0°、未鏡像、偏移 0、寬 16.01 mm、高 130 mm。
3. 按「滑鼠繪製」，沿櫃體底部同高端點點選。
4. 第一段如厚度朝內，按 F 或面板「方向切換」；此方向會保留到完成。
5. 繼續沿四邊繪製，回到起點點擊閉合。也可 Space/Enter 完成開放路徑。
6. 確認轉角前後皆直立，閉合及完成時不翻向，結果為獨立群組。
7. 若要畫垂直框線，結束或取消後改選「牆面／空間（原方式）」，再重新起筆。

驗證：
- Python 語法檢查。
- 新增水平案例：8 種矩形起筆/行進順序 × 2 種厚度側，涵蓋第一段至四段、閉合網格無開口、16.01/130 mm 寬高、預覽與提交一致。
- 模擬兩種工具入口的滑鼠狀態、起筆法線、F 反向、Backspace 重選首段、完成參數一致。
- 舊版測試一項需要缺少的 v1.6 ZIP，無法執行；未把它列為通過。
- 離線幾何與模擬事件測試不代表 Windows 的滑鼠吸附與畫面已實機驗證。
