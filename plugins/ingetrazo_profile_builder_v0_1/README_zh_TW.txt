v2.2.3 試用修正版｜實際模型定位：單／雙精度座標造成邊線分類漏配

實際案例：使用者上傳 untitled(1).igz，確認為新版生成的常用踢腳。
根因：掃掠產生的座標是 Python 雙精度，Mesh.add_face 則存為 QVector3D 單精度。舊 _mesh_vertex_key 直接將原始數值取整至微米；在離原點約 6 公尺的位置，一部分邊線兩端落入不同的微米格，未能套用隱藏／柔化。
修正：所有邊線比對鍵先經過與 QVector3D 相同的 float32 轉換，再量化；不更動模型的實際座標或尺寸。

實際模型結果：
- 踢腳 375 頂點、746 面、1119 邊，剖面有 125 個節點。
- 內部分割線隱藏：392 → 494 條，全部對應。
- 非隱藏弧面柔化線：182 → 234 條。
- 本次共修正 154 條邊線的顯示標記。
- 修正後測試模型僅更動該踢腳的 154 個邊線旗標位元組。
- document.json、所有座標、面索引與其他幾何區塊逐位元組維持原樣。
- 重新載入修正模型後再次核對標記數量一致。

上方磁碟片圖示現在用於「儲存最後一次使用狀態」。請先選取剖面並調好尺寸、角度、鏡像等設定，再按磁碟片。下次開啟快速輪廓生成器面板會還原這組設定。
只有按下磁碟片才會更新紀錄；平時調整與關閉程式不會自動儲存。
原始剖面資料庫及縮圖不會被覆寫。若需要新建／另存線板至資料庫，使用「進階設定 → 另存剖面到資料庫」。
狀態儲存位置：%APPDATA%\ingetrazo\quick_profile\last_saved_use.json。

v2.0.2 補充：自訂剖面尺寸
- 選取模型中一個封閉面，點擊上方「新增」並儲存新剖面。
- 新剖面自動讀取實際幾何外框寬高，更新面板寬高（mm）。
- 從資料庫切換至既有自訂剖面時，也會恢復該剖面的原始幾何尺寸。
- 已手動按「儲存」的最後使用狀態在重開外掛後仍優先還原；不會自動覆寫該儲存狀態。
- 此次不修改轉角幾何演算法。

【v2.0.3 自訂剖面預覽方向修正】
選取一個封閉平面後使用「新增」擷取。立面剖面固定以上方 +Z 為上；水平面使用世界 +X / +Y 基準，避免模型的頂點順序造成縮圖顛倒或旋轉。原有剖面檔案不自動覆寫；要修正舊的縮圖請重新擷取來源面並手動儲存。

【v2.0.4 預覽比例修正】
剖面預覽以毫米尺寸及單一縮放倍率描繪；例如 40.22 x 21.84 mm 的剖面，在未旋轉時應呈現約 1.84:1 的外接框比例。

【v2.0.5 修正】
- 資料庫刪除自訂剖面時，修復 read_owned 未定義造成的錯誤。
- 等比例縮放會鎖定「勾選時」目前寬高比；不會直接變成 1:1。
- 若先取消等比例、分別修改寬高，再勾選，會以新尺寸比例為準。
- 切換剖面後會使用該剖面的原始比例；重置會還原原始尺寸。
- 刪除自訂剖面時仍依原有方式備份，不會刪除 SKP 原始檔。

- 刪除自訂線板後，原生資料移入 .quick_profile_removed 備份資料夾；SKP 原檔不刪除。

【v2.1.3 實驗版滑鼠繪製】
按下黃色「實驗中」即可使用第二套滑鼠繪製工具。左鍵點取節點、方向鍵鎖軸、Space / Enter 完成，Esc 取消。此模式使用獨立的三維掃掠演算法，平面路徑暫沿用穩定核心。原本「滑鼠繪製」按鈕不受影響。此功能尚需 IngeTrazo 實機驗證。

v2.1.4 實驗版牆面方向：
- 按「實驗中」開始第二套滑鼠繪製；盡量從牆面吸附點起筆。
- 目前選定的牆面方向會鎖定到完成，避免中途忽然翻面。
- F 反轉裝飾正面；如果是垂直起筆、軟體沒有提供牆面法線，可用 Tab 切換 XZ / YZ 牆面基準。
- Space / Enter 完成，Esc 取消；這些快捷鍵只影響實驗模式。
- 尚未經過 Windows IngeTrazo 0.6.0 實機測試；不支援跨不同牆面的非共面自動換面掃掠。
