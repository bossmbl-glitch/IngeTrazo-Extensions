# 材質編輯器 v0.5.1

先選取需要上色的面／群組，再選材質或調色，就會一次套用到全部選取。群組內可按 Ctrl+A 全選面，不需逐面上色。

- B：油漆桶。點已選取的面／物件，一次塗全部選取；點未選取的面／物件則塗該物件。
- 按住 Alt＋點模型：滴管吸取，不上色；放開 Alt 恢復油漆桶。
- M：開啟材質編輯器（已安裝 MAX 快捷鍵）。
- 面板上方「套用到全部選取面／物件」可直接整批套用。
- 點材質庫色塊時，有選取就直接套用全部選取；沒有選取則切換油漆桶。
- 拖曳調色以目前選取範圍為優先，原本混合不同材質的面會一起變色。未選取但使用相同材質的面不會跟著被改色；需要時會建立獨立材質。
- 未選取時保留編輯整份模型同名材質的功能。
- Ctrl+Z 可一次復原整批上色或一次連續調色。調色保留原貼圖座標；不改幾何形狀。

B 已改給油漆桶，下視圖使用 Ctrl+7。可在偏好設定中繼續自訂快捷鍵；重啟不會重設自訂。

使用者的 1216框.dae（432 面）已在安裝版 IngeTrazo 0.5.11、RTX 5070 上測試混合材質全選調色、點材質整批套用、B 鍵、Alt 吸取後恢復塗色、一次復原重做與 IGZ 儲存重開。測試使用獨立模型與設定。
