UV 貼圖（滑鼠版）0.3.0
適用於已測試的 IngeTrazo 0.5.11；繁體中文。

這是獨立外掛，不需要安裝「固定邊框縮放」，也不需要舊的 it_uv_deform。

操作
1. 點工具列「UV 貼圖」，不會跳出參數視窗。
2. 點選面或群組，再按滑鼠右鍵。
3. 選「UV 投影方式」→ 平面、盒狀、圓柱、球面、四邊面鋪滿、依目前視角。
   無圖片材質時，先右鍵「載入貼圖圖片」或「套用檢查格」。
4. 投影方向及貼圖大小，也在右鍵選單內設定。

直接用滑鼠調整
・單一有貼圖的面：點選後會出現貼圖釘；選好該面再按工具按鈕也可以。
・直接拖曳面上的貼圖或紅釘：移動。
・拖曳綠釘：旋轉及縮放；Ctrl 可取消原生的角度吸附。
・拖曳藍釘：拉伸／剪切。
・黃色透視變形釘是主程式尚未實作的功能。
・Enter 或右鍵「套用拖曳結果」完成，之後仍保持 UV 工具，可繼續選面。
・Esc 取消目前貼圖位置調整；右鍵也可取消。
・旋轉 90 度、水平／垂直鏡射都在右鍵選單。
・切換到其他工具時會套用已拖曳的貼圖位置；Ctrl+Z 可復原。
・群組整體可做 UV 投影；要拉單面的貼圖釘，先雙擊進入群組，再點該面。

進階功能
右鍵「進階 UV／匯入匯出」保留 UV 快照、OBJ UV 往返與精確數值調整。
OBJ 往返只可編輯 UV，不可改幾何、坐標軸或單位。匯出坐標為公尺。
圓柱／球面／四邊面及 OBJ 載回可能三角化選取面；操作可復原。
投影及進階調整目前處理正面材質。
選取外部元件時獨立化；進入元件編輯模式後仍遵循主程式的共用定義行為。

安裝
1. 解壓縮 IngeTrazo_MouseUV_v0.3.0.zip。
2. 將 it_mouse_uv 資料夾放入「擴充功能 → 開啟外掛資料夾」。
   正確層級：plugins/it_mouse_uv/__init__.py。
3. 儲存模型後，關閉並重開 IngeTrazo。
4. 工具列或「擴充功能 → UV 貼圖」皆可啟用。
若自行升級，請將舊 it_uv_deform 移到 plugins 外，避免舊的合併版仍出現。
可獨立移除本外掛，不影響固定邊框縮放。
