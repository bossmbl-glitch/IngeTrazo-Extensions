燈具生成器 1.0.2 — IngeTrazo
製作日期：2026-11-04

安裝
1. 解壓縮「IngeTrazo_燈具生成器_v1.0.2.zip」。
2. 在 IngeTrazo 選擇 Extensions → Open plugins folder（擴充功能 → 開啟插件資料夾）。
3. 將完整的 it_lighting_generator 資料夾複製進去。
   Windows 預設目的地：%APPDATA%\ingetrazo\plugins\it_lighting_generator
   資料夾內必須直接看得到 __init__.py、engine.py、ui.py、models 與 previews。
4. 儲存目前工作後，重新啟動 IngeTrazo。
5. 在 Extensions 選單選「燈具生成器…」，或按工具列燈具圖示。
   快捷鍵 Ctrl+Alt+L；若此快捷鍵已被其他插件使用，請從選單開啟。

使用
• 選擇型號，或輸入 QC1、QA1、M8 等關鍵字搜尋。
• X / Y 方向顆數都設為 1，即放置一顆。
• 設為 1×N 即產生一排；設為 M×N 即產生矩陣，最多 400 顆。
• 間距是燈具錨點的中心間距，單位 mm；整體比例不改變間距。
• 平面旋轉以世界 Z 軸為中心，同時旋轉燈具與排列方向。
• 預設使用原模型「position」定位線的中心作為安裝錨點。
  頂面／底面中心是模型外包圍盒的頂面／底面中心，可依需求切換。
• 預設固定安裝標高 2800 mm，是世界 Z 的絕對值，不是離點選表面的高度。
  取消勾選「固定安裝標高」時，直接採用滑鼠捕捉點的 X、Y、Z。
• 點「開始放置」，移到場景點選第一顆燈的位置。
• 勾選「連續放置」可連續點選；Esc 結束。點選前按 Esc 不會插入模型。
• 每次點選所放置的全部燈具是一組；Ctrl+Z 復原整組，Ctrl+Y 依宿主設定重做。
• 放置後可使用 IngeTrazo 的移動、旋轉、縮放工具調整。
• 從群組編輯模式啟動時，會先離開編輯模式；燈具放在場景最上層。
• 滑鼠放置時會顯示帶材質的實體預覽，點選前不會寫入場景。

模型庫
共有 21 款，全部由使用者提供的「燈具全.skp」直接解析轉製：
C1、C5、M2、M5_25、M8、M8_N3；
QA1_F1、QA1_F2、QA1_F3、QA1_N1、QA1_N2、QA1_N3；
QC1_F1、QC1_F2、QC1_F3、QC1_N1、QC1_N2、QC1_N3；
QM5_25_F1、QM5_25_F2、QM5_25_F3。

原始造型、尺寸、面材質與巢狀組件經 IngeTrazo / OpenSKP 匯入流程保留。
全部燈具均保留原定位輪廓，並增加 16 mm 中心十字線；中心是可捕捉的實際頂點。
定位線框位於原定位面，只有線而沒有填面；可在群組內選取「定位線框・中心點」。
QA1 與 QM 系列共移除 9 片獨立的內部矩形面，正常燈框與燈頭保留。
模型庫已內含 .igz 資產，執行時不需要原始 .skp，也不需要 SketchUp。
這是模型放置／排列生成器；沒有重新繪製可任意改燈頭結構的參數模型。
不會自動在天花板開孔，也不會建立 D5、Enscape 或 Blender 的渲染光源。
預覽是依實際幾何產生的示意圖，不是照明模擬。

相容性與驗證
在官方 IngeTrazo v0.5.11 原始碼與 0.6.0 原始碼分別執行測試。
各 38 項通過：21 款資產尺寸／面數、定位線框與中心點、排列與旋轉、比例與間距、
頂底錨點、參數驗證、連續放置、標高、取消、材質名稱衝突、復原／重做、
.igz 存取、中文介面，以及原生主視窗與插件 API 的整合。
新增啟動後延遲載入工具列的回歸測試。
另以電腦已安裝的 IngeTrazo 0.5.11 執行檔，在獨立測試視窗使用 NVIDIA 視埠
與 Rust 引擎確認 QA1_N2 的實體滑鼠預覽、放置後渲染及工具列 icon 可見性。
1.0.2 另外確認 QA1_F2 與 QM5_25_F2 移除多餘面後的原生渲染與定位線框。
未在使用者正在編輯的視窗中進行測試。
未修改現有 IngeTrazo 專案，也未使用本機 SketchUp 進行轉檔。

1.0.2 舊燈具更新
新放置的燈具會直接使用新版模型。
已放置的舊燈具：先選取燈具或排列組，再選 Extensions →
「更新選取燈具（模型與定位框）」。這會重建所選生成器的內部幾何，
保留外層位置、角度、比例與排列設定，並加入定位線框。Ctrl+Z 可以復原。
手動修改過內部幾何或材質的燈具，更新時會以模型庫內容取代那些內部修改。

1.0.1 修正
• 修正主視窗顯示後才載入插件時，工具列沒有明確顯示的問題。
• 工具列僅顯示 icon；延遲版面還原後再次確保可見。
• 滑鼠放置改用原生外部組件實體預覽；取消或完成時清除預覽。

解除安裝
關閉 IngeTrazo 後，將上述插件資料夾移出 plugins 目錄再重啟。
既有專案中的燈具是原生幾何，移除插件後仍可開啟與編輯。
