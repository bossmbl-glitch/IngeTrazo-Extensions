# 快速輪廓生成器｜已知限制

目前正式版為已驗收的 v2.2.4；舊 v0_1 目錄名稱保留作相容用途。

- 暫存剖面未另存且未生成物件時，程式結束後不保留。
- 取面／沿面外框仍限場景主網格的單一無孔平面；不新增巢狀群組內取面或帶孔剖面支援。
- 路徑不接受分岔；水平踢腳要求同高，固定牆面不自動跨牆。
- 編輯限保存剖面資料的本套件頂層群組；鎖定、含子物件、拓撲修改、局部變形或已推拉物件可能無法安全重建。
- 重建遇到逐面不同材質／屬性時，需明確勾選統一材質才能處理。
- 轉角僅斜接、平接；擠出僅「一般」。複雜非共面、自交或尖角仍有限制。
- SKP 僅接受可由 IngeTrazo 解析的單一共平面、封閉、無孔剖面。
- 舊線板不會隨安裝自動清理，需編輯重建；選取、隱藏幾何或線框模式可能顯示額外提示線。

測試版已獲使用者確認可用。自動化驗證在 Linux 離屏 Qt 執行；未宣稱涵蓋 Windows 全情境、真實滑鼠吸附或大型專案。1 支舊測試缺歷史 v1.6 ZIP 而略過。

## v2.2.5 測試版新增提醒（待驗收）

- 附圖是使用目前參數計算的固定短路徑示意，實際路徑仍看模型預覽。
- 新立放僅適用新繪製的固定牆面壁板；沿選取路徑、沿面外框、戳記、空間模式與舊壁板規則不變。
- mm寬高仍代表原剖面尺寸；立放後原寬成為沿牆高度、原高成為凸出厚度。
- 未取得使用者自訂066原始剖面，需以實際檔案進行Windows驗收。

## 路徑編輯測試版2限制

- 一次一個具有完整路徑與剖面資料的頂層線板；不支援戳記、元件實例或含子物件群組。
- 手改拓撲／局部變形或逐面不同材質屬性無法安全重建，會拒絕編輯。
- 踢腳鼠標移動固定在原高度，壁板固定在原牆面；不新增跨牆能力。
- 路徑是折線節點，最多2048點；不提供弧線控制柄。
- Linux離屏Qt使用模擬空間輸入與投影，Windows真實吸附及OpenGL顯示仍待驗收。


## v2.2.5 測試版3（2026-11-25，待驗收）

半透明預覽為QPainter投影覆蓋層，沒有OpenGL深度遮擋與材質光照，原線板仍可見；大型路徑可能較慢，可取消預覽。
紅色診斷標示第一個已知錯誤，並非任意3D幾何碰撞檢查。空間路徑對齊使用世界XY；不新增跨牆、弧線控制柄或巢狀群組支援。
吸附沿用主程式結果；固定平面／軸鎖定會投影位置，介面會提示。實際Windows滑鼠吸附及OpenGL場景仍待驗收。
取消、Esc、關閉視窗或切換工具，只放棄最後一次套用後的未提交內容；已套用內容需模型Undo。

## v2.2.5 測試版4限制


- 半透明仍為QPainter投影覆蓋層，沒有OpenGL深度遮擋／材質光照；未新增跨牆、巢狀或弧線控制柄。
- 尺寸標籤避開節點、視窗邊界與其他標籤；縮得太小時部分不顯示。超過32段時只顯示選取線段尺寸；仍可用更多工具指定線段編號改長度。
- 尺寸輸入的固定端指路徑起終點，與畫面左／右不一定相同。
- 尺寸與預覽跟隨工作路徑，不等同包覆外緣尺寸。基本拖曳使用滑鼠；更多工具保留原點選後定位方式。
- Windows／IngeTrazo 0.6.0實際滑鼠吸附、OpenGL子控制項顯示及效能仍待使用者驗收。

## v2.2.5 測試版5限制

- 一次處理一個轉角；開放路徑端點不能倒角。圓角套用後是折線節點，不保存可重新輸入R值的獨立圓弧物件；可先局部復原再重做。
- 尺寸以路徑為準，並非線板內外緣；圓角段數越多計算與節點越多。
- 沿用既有掃掠與斜接／邊線分類；半徑過小或剖面過大仍可能造成線板表面重疊，需看預覽並實機核對。不是完整實體碰撞檢測。
- 半透明仍為QPainter覆蓋層，不具OpenGL深度遮擋。未新增跨牆、巢狀群組或獨立曲線控制柄。
- 原主面板剖面寬高仍mm；新轉角欄位cm會正確換成公尺，未更改既有儲存格式或float32邊線鍵。
- Windows真實滑鼠、吸附、OpenGL顯示與大型專案效能仍待使用者驗收。

## v2.2.5 測試版6限制

- 斷開是移除當前封閉路徑的選取整段，接合是連接當前開放路徑的首尾；不是跨群組合併，也不將一條開放路徑拆成兩個群組。
- 直角／節點對齊只在固定或可推定共平面路徑提示；原生端點／中點／交點吸附與手動軸鎖優先。直角需接近3度且畫面8px內；對齊約7px內。
- 整框尺寸用路徑在工作平面的寬高，不含剖面外緣。非共面、寬高為零或會移動鎖點時拒絕；固定在鎖點的角可保留鎖點。
- 多選拖未鎖節點只移動可動部分；直接拖有鎖定端點的整段會拒絕，避免誤改固定角。
- 尺寸密集或畫面太小仍會隱藏部分標籤；超過32段只顯示選取線段尺寸。
- 超過80點拖曳採簡化預覽，放開後才顯示完整錯誤診斷；未宣稱已完成Windows大型專案效能基準測試。
- 退出提示保護外掛小工具列、Esc及主面板關閉；主程式直接切換其他工具仍按既有行為放棄未提交內容，不修改原生工具切換流程。
- 複製副本預設仍在原位；如未修改路徑就完成，會得到重疊但獨立的副本，需自行調整位置／尺寸。
- 沿用前版單一頂層線板／完整生成資料／無手改拓撲及逐面異質屬性限制。圓角仍為2至64段折線，非可參數重編輯的獨立圓弧物件。
- 半透明為QPainter覆蓋層，沒有OpenGL深度遮擋，且不具完整實體碰撞檢查。Windows真實滑鼠、吸附、OpenGL與實際專案仍待驗收。
