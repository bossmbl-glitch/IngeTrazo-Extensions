# 快速輪廓生成器

- **管理 ID：** PB-01
- **目前正式版：** v2.2.5（2026-11-25）
- **前一正式版：** v2.2.4
- **目標平台：** Windows x64 / IngeTrazo 0.6.0 / Python
- **程式目錄：** `plugins/ingetrazo_profile_builder_v0_1/`（目錄名稱維持相容，不代表版本仍為 v0.1）
- **單位：** 使用偏好 cm；現有寬高／偏移／剖面資料使用 mm，模型內部使用公尺。

## 正式版下載與安裝

[下載 v2.2.5 正式版及查看安裝說明](releases/v2.2.5/README.md)。

選取單一無孔平面後按「＋」，可立即使用暫存剖面，不需先命名。需要保存時，使用「進階設定 → 另存剖面到資料庫」。上方磁碟片仍用於儲存個別參數。

暫存剖面不自動進入圖庫；未另存也未生成物件的剖面不跨程式啟動保存。生成物件內嵌剖面資料，可隨專案保存、再吸取及編輯。
