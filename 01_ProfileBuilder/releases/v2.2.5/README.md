# 快速輪廓生成器 v2.2.5 正式版

[下載正式安裝包](Lime_Quick_Profile_IngeTrazo_v2.2.5_Release.zip) · [v2.2.4 至 v2.2.5 完整更新紀錄](CHANGELOG.md) · [SHA-256](SHA256SUMS.txt)

快速輪廓生成器 v2.2.5 正式版｜Windows x64、IngeTrazo 0.6.0
1. 關閉 IngeTrazo，把現有 ingetrazo_profile_builder_v0_1 備份到 plugins 以外。
2. 將 ZIP 內同名資料夾放入 %APPDATA%\ingetrazo\plugins\。
3. 重啟並確認面板顯示 v2.2.5 正式版。要回復時關閉程式，再放回舊版備份。
