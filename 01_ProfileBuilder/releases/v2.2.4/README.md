關閉 IngeTrazo，把舊 ingetrazo_profile_builder_v0_1 備份到 plugins 外，再將 ZIP 內同名資料夾放入 `%APPDATA%\ingetrazo\plugins\`。不要同時載入新舊兩份。

按「＋」可立即使用暫存剖面；需要保存時，才使用「進階設定 → 另存剖面到資料庫」命名。上方磁碟片維持儲存個別參數的用途。
