# IngeTrazo 擴充套件開發總清單

文件版本：1.0  
整理日期：2026-11-12  
目標平台：IngeTrazo 0.6.0  
作業系統：Windows x64  
預設單位：cm  
介面語言：繁體中文

## 1. 開發原則

- 以 IngeTrazo 為目標，不預設 SketchUp Ruby API 相容。
- 使用者未明確要求實作時，只進行分析、規劃與紀錄。
- 各外掛獨立維護原始碼、版本及更新紀錄。
- 新版不得無故破壞既有功能。
- 正式版必須通過實際應用程式測試。
- 所有狀態以最新原始碼、測試報告及正式安裝包為準。

## 4. 已知重點問題

### Profile Builder
- 巢狀群組及跨越外框
- 交叉幾何及部分重疊
- 線板多餘線段
- 戳記破面及推拉失敗
- X/Y/Z 軸鎖定方向
- 剖面資料庫及狀態記憶

### Cabinet Builder
- 門片與門框連動
- 門片預設內退 2 cm
- 正反面裝飾線方向
- 抽屜及門片參數同步
- 把手位置、群組與材質
- 對開門、玻璃門及 C 型把手

### FFD
- 未選取控制點不應變形
- 單側變形不得連動另一側
- 向上變形異常
- 高面數模型支援

### Vent & Light
- 起點、終點繪製失效
- 依長度自動配置構件
- 保留原始材質
- 不同模型的相容性

## 5. 版本管理

每個外掛應建立：

- README.md：功能與安裝說明
- CHANGELOG.md：歷次版本更新
- SPEC.md：功能規格
- KNOWN_ISSUES.md：已知問題
- TEST_REPORT.md：測試紀錄

正式版及試用版分別保存。

## 6. 狀態判定

- 已規劃：有需求但未確認程式實作
- 已開發：曾有實作紀錄，但未重新驗證
- 測試中：已取得安裝包並進行驗證
- 已驗收：指定版本通過真實模型測試
- 正式發布：已驗收並具備完整版本紀錄
