IngeTrazo-D5-LiveSync 0.9.10-test.5｜專案移機測試版
包含 test.3 材質識別保留、test.4 自動橋接備份與還原。
D5 在公用伺服器上：本移機包不包含 D5 專案或任何 D5 資產，也不搬動或修改伺服器檔案。

先安裝
1. 停止同步、關閉 IngeTrazo，將外掛舊資料夾備份到 plugins 以外。
2. 完整備份 %LOCALAPPDATA%\IngeTrazoD5Bridge\projects\，保留同時期 IGZ 與 D5 測試副本。
3. 將本 ZIP 的 ingetrazo_d5_livesync 資料夾放入 %APPDATA%\IngeTrazo\plugins\，取代同名資料夾。
4. 兩台使用相同 test.5；官方 D5 Blender 外掛仍需相容版本 1.0.0.0028。重新設定各台自己的 Blender／D5 安裝路徑。

舊電腦匯出
1. 確認模型、D5 材質正常且最後一輪同步完成，儲存對應 IGZ；保留伺服器 D5 專案的測試副本／可回復版本。
2. 停止同步並等背景 Blender 結束。設定 →「橋接備份與還原…」→「匯出移機包…」。
3. 將 ZIP 儲存在 projects 專案資料夾以外，待匯出完成。大檔案驗證與壓縮可能耗時，介面會暫時等待。
4. 帶走此移機 ZIP 與剛儲存的原始 IGZ。不要把完整外掛安裝 ZIP 當成專案移機 ZIP。

新電腦匯入
1. 先開啟剛帶來的原始 IGZ，不建立新同步關聯、不按開始。IGZ 內需有原本的 bridge_project_id；識別不同會拒絕。
2. 設定 →「橋接備份與還原…」→「匯入移機包…」。即使本機尚無 projects/<識別> 也可匯入。
3. 選擇移機 ZIP，確認後等待所有雜湊與配對驗證。現有本機還原點會保留；現有橋接檔在安裝前會另作 rescue 保全。
4. 完成後仍停止同步。使用公用伺服器上同一個 D5 專案的測試副本，先檢查材質完整，再手動開始同步驗收。
5. 匯入後不必手改 Windows 使用者路徑。配對紀錄會改到本機路徑；.blend 保持原始位元組，worker 載入後只重綁本橋接器的來源標記。
6. 不要讓兩台電腦同時對同一份 D5 專案同步，也不要在不同分歧 IGZ 之間輪流傳送。每次移交應重新匯出最新配對。

移機包內容
- 目前已成功確認的橋接配對，以及新版 bridge-backups 內所有可驗證還原點。
- 每點含 bridge.blend、scope-cache 對應快照、確認紀錄、備份中繼資料；外層 transfer.json 記錄版本、識別與 SHA-256。
- 不含原始 IGZ、D5 專案／資產、Blender／D5 程式、本機安裝設定、sessions 暫存、舊 optimization-backups、rescue 原始證據。
- scope-cache 裡的 IGZ 是橋接配對快照，不能當作帶給新電腦編輯的原始 IGZ。
- 若尚無已確認配對，或任一列出的還原點損壞，會拒絕匯出；不會猜測補造有效 SDK 識別。

失敗與回復
- 身分／格式／雜湊錯誤在 staging 階段拒絕，不安裝到目前橋接資料。
- 開始安裝後若失敗，現況保全與還原交易沿用 test.4；未完成回滾下次啟動先處理，不直接傳送。
- 安裝中已複製完成的匯入還原點可能保留在列表；不會覆寫既有備份或自動清理證據。
- 不保證硬碟實體故障或所有檔案系統的斷電持久性；移機 ZIP 與舊電腦原資料應另外保留。
