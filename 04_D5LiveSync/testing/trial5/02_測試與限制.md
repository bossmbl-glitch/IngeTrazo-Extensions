# 0.9.10-test.5 移機實作與驗證

來源：develop dc9011e（遠端唯讀核對未變），本地 HEAD a5e39dd，加上尚未提交的 test.3／test.4 修改。未執行 Git 變更，未發布正式版。

新增 project_transfer.py；修改 backup_ui.py、worker.py 及版本資訊。保留原 UID、名稱、D5 SDK 屬性、材質、UV、圖層政策演算法。

移機包只收橋接配對與新版已確認備份。不含公用伺服器上的 D5 專案／資產；亦不含原始 IGZ。必須先開啟有相同 bridge_project_id 的原 IGZ，不會替使用者改換文件識別。另存的同識別文件仍共用橋接專案，沒有自動分支功能。

每檔先驗證 ZIP 外層 SHA-256，再核對每個還原點內層 SHA-256／配對／原始路徑及專案。拒絕路徑穿越、重複 ZIP 項目、額外檔案、符號連結及不符識別。限制 20,000 檔／解壓總量 100 GiB。匯出使用暫存檔，驗證完成才取代目的 ZIP。

匯入所有檔案先在 staging 驗證，再重新綁定狀態紀錄的目的路徑並更新其雜湊。所有 .blend 維持原始位元組；worker 載入已驗證配對後，在任何模型匯入前只調整 ingetrazo_doc／ingetrazo_scene_doc／ingetrazo_ambience_doc。遇未知來源整輪停止，先檢查全部標記才套用，避免半套重綁。SDK UUID 與幾何不重建。

匯入取得本機 ProjectLease 後合併備份（不覆寫、不輪替舊點），沿用 test.4 的現況保全、還原日誌及回滾。未完成交易在 worker 開始時恢復；失敗後已複製成功的備份可保留。新電腦沒有舊配對時，rescue 會記錄原檔不存在。匯入完成不啟動同步。

本地測試：95 項通過（既有 78 項＋17 項新增移機／Qt 測試）。完整輸出見 03_本地自動測試.txt。Linux／Python 3.12／PySide6 6.11.3，原宿主 API 使用官方 IngeTrazo 0.6.0 e61132a。測試包含真實暫存檔、ZIP、SHA-256、系統檔案鎖及 offscreen Qt；.blend 內容、Blender datablock 與 SDK 回報使用替身。另做語法編譯、worker／UI 匯入、diff 格式及安裝包每檔雜湊檢查。

尚未驗證：Windows 檔案存取、真實 Blender 存取、官方 SDK 在不同使用者路徑下的連線繼承、D5 伺服器專案材質／貼圖／UID／燈光與效能。因此「橋接位元組與 SDK 屬性保留」是實作保證，不等於已證實 D5 在新電腦首輪會保留所有覆寫。實機失敗時應停止並保留診斷，不在正式檔反覆試送。

本機鎖不能阻止不同電腦同時連同一個 D5 專案，需由使用者停止另一台；不提供伺服器跨機鎖。不搬動 D5 資產，不偵測或驗證伺服器 D5 檔案內容／版本，也不會救回以前已遺失的 SDK UUID。IGZ／D5／橋接配對仍需由使用者保持同一時期。

匯出壓縮／驗證與匯入目前在停止後的介面中同步執行，大模型可能暫時等待且增加磁碟需求；需容納移機 ZIP、staging、匯入備份及 rescue。舊 optimization-backups／未知或損壞證據不轉換進移機包，仍留原機。保留外部副本，不保證物理磁碟故障或所有斷電情境。
