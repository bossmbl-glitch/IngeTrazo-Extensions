# IngeTrazo D5 LiveSync 0.9.11

本次彙整自 **0.9.9 至 0.9.11** 的累積更新，改善同步效能、既有 D5 材質關聯保留、圖層控制與橋接資料備份，並整理日常操作介面。上一個正式版為 0.9.10；本版包含後續移機、圖層保留及兩輪 0.9.11 整合改善。

## 同步效能與穩定性

- 新增完整同步原因紀錄，方便查明哪些變更觸發更新，以及退回完整同步的原因。
- 改善移動／旋轉及局部形狀／材質更新，涵蓋材質工作室上色、群組編輯、復原／重做等操作；無法確認影響範圍時保留完整同步退路。
- 排除單純視角移動造成的同步，略過已確認沒有內容變化的重複傳送。
- 純圖層可見性切換符合條件時使用小型更新，減少完整模型匯出與幾何重建。
- 同步失敗後重用已準備的模型；若 D5 已接收、僅橋接保存失敗，重試保存時不再次傳送同一模型。
- 改善 D5 關閉偵測，關閉後自動停止背景同步。

## 材質關聯與圖層保留

- 修正圖層排除後恢復正常時，其他圖層材質關聯可能被重置的問題。
- 保留既有物件識別、材質分支、UV 與 SDK 屬性；遇到無法確認的對應時停止更新並提示。
- 新增具名材質關聯帳本，優先延續既有材質身分，不因同名來源外觀改變而自動建立新身分。
- 同名材質預設保留已確認外觀；需要不同呈現時，請在 IngeTrazo 建立不同名稱。
- 材質衝突置頂、標紅並顯示原因，不自動改名或合併。
- 「暫時不更新」圖層可在 IngeTrazo 關閉以方便建模，D5 維持最後成功同步的內容；恢復正常後才跟隨來源顯示。

## 橋接備份與還原

- 新增 BLEND 與配對快照的備份、完整性驗證及時間點列表。
- 自動備份可設 **1～1440 分鐘**，預設 10 分鐘。
- 一般定時備份只留最新 **6 份**；第 7 份成功保存後輪替最舊一份。
- 背景同步程序運作且有有效資料時，每半小時建立保護點；保護點與手動保留點不占六份名額，不受一般輪替刪除。
- 備份複製、驗證及清理移至背景處理；相同檔案可共用儲存，減少重複占用。
- 新增日期篩選、容量資訊、單筆及日期範圍刪除；刪除保護點需要明確確認。
- 支援停止同步後選擇時間點還原，先保全現況，完成後不自動同步。
- 未完成備份保留任務紀錄，供下次啟動重試。

## 跨電腦移機

- 新增橋接移機包匯出／匯入，攜帶橋接識別、配對資料、備份及材質關聯帳本。
- 支援不同 Windows 使用者路徑，匯入前驗證完整性並保全現況。
- **不包含 D5 專案或資產**；沿用公用伺服器上的 D5 專案，IGZ 需另外保存並攜帶。

## 操作介面與診斷

- 日常操作整理為 **「暫停、繼續、重新整理」**；重新整理可在暫停期間更新一次，完成後仍維持暫停。
- 進階操作預設收合，集中啟動連線、停止同步及強制完整更新等功能。
- 同步狀態視窗顯示進度、耗時與結果；關閉視窗不會停止同步。
- 設定面板與狀態視窗皆可匯出診斷包，自選資料夾與檔名，記住上次成功位置。
- 診斷包預設檔名加入時間，降低誤用舊紀錄的機會。

## 安裝與升級

停止同步並關閉 IngeTrazo，先備份完整 `%LOCALAPPDATA%\IngeTrazoD5Bridge\projects`、IGZ 與 D5 專案。將 ZIP 內 `ingetrazo_d5_livesync` 資料夾放入 `%APPDATA%\IngeTrazo\plugins\`，取代同名外掛；首次更新使用 D5 副本核對模型與材質。
